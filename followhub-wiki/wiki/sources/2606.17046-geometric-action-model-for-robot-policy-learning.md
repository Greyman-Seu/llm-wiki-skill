# Geometric Action Model for Robot Policy Learning

## 太长不看

GAM 值得记住的不是“给 VLA 再加一个深度分支”，而是把几何基础模型本身改造成世界—动作模型：浅层编码当前多视角几何，中间因果预测未来潜状态，深层共同解码未来几何与动作。它以 1.4B 参数在 LIBERO-Plus 达到 85.5%，相机扰动达到 83.1%，推理仅 6.9 ms，说明显式几何先验可以同时改善 OOD 鲁棒性与控制效率。

## 直观理解

可以把 GAM 理解成在一台已经会从多视角图像“搭三维场景”的模型中间装入时间轴。前半段把当前画面变成几何 token；中间模块根据语言、机器人状态和刚执行过的动作，猜下一时刻这些几何 token 会怎样变化；后半段再把这个“未来几何”同时翻译成未来深度与下一段机器人动作。

## 背景与问题

**动机：** 通用操作策略不仅要识别物体和理解语言，还要在相机视角、机器人初始位姿和遮挡改变时判断接触几何与动作后果。VLA 借助 VLM 获得开放词汇语义，视频 WAM 借助生成模型获得时序先验，但二者主要在二维图像或二维潜空间中工作；深度、尺度、遮挡和跨视角一致性只能由动作头间接恢复，容易在需要空间外推的扰动下失效。

**问题缺口：** 已有几何感知策略要么从点云训练任务专用编码器，要么只把 GFM 当静态特征提取器，通过蒸馏、对齐或末端动作头被动利用其输出；它们没有把 GFM 的多层几何结构变成策略自身的时序预测与动作生成通道。论文要回答的是：能否以最小结构改造复用一个预训练 GFM，在同一潜空间中联合学习未来世界几何和动作，同时保留实时性与 OOD 相机鲁棒性。

## 论文摘要（英文原文）

Generalist robot policies must follow user instructions while reasoning about how objects, cameras, and robot actions interact in the 3D physical world. Recent vision-language-action models (VLAs) and video world-action models (WAMs) inherit strong semantic or temporal priors from large-scale foundation models, but they still operate primarily on 2D image frames or 2D-derived latent spaces, leaving implicit the 3D geometry required for contact-rich manipulation. We propose the Geometric Action Model (GAM), a language-conditioned manipulation policy that directly repurposes a pretrained geometric foundation model (GFM) as a shared substrate for perception, temporal prediction, and action decoding. GAM splits the GFM at an intermediate layer: the shallow layers serve as an observation encoder, and a causal future predictor inserted at the split layer forecasts future latent tokens conditioned on language, proprioception, and action history. The predicted future tokens are then routed through the remaining GFM blocks for feature propagation and decoding, allowing a single backbone to produce both future geometry and actions. This design equips the GFM with language-conditioned temporal world modeling through minimal architectural modification while preserving its rich geometric priors. Across a broad suite of simulation and real-robot manipulation benchmarks, GAM is more accurate, more robust, faster, and lighter than current foundation-model-scale baselines.

## 论文摘要（中文翻译）

通用机器人策略既要遵循用户指令，也要推理物体、相机和机器人动作如何在三维物理世界中相互作用。近期视觉—语言—动作模型（VLA）和视频世界—动作模型（WAM）继承了大规模基础模型的强语义或时序先验，但仍主要工作在二维图像帧或二维派生潜空间中，因此接触密集操作所需的三维几何仍是隐式的。作者提出 Geometric Action Model（GAM），一种语言条件操作策略，直接把预训练几何基础模型（GFM）改造成感知、时序预测和动作解码的共享基底。GAM 在中间层切分 GFM：浅层作为观察编码器，在切分处插入因果未来预测器，并以语言、本体状态和动作历史为条件预测未来潜 token；这些未来 token 再经过剩余 GFM block 做特征传播与解码，使同一骨干同时生成未来几何和动作。该设计只做少量架构修改，就赋予 GFM 语言条件的时序世界建模能力，同时保留其丰富几何先验。作者在多组仿真和真实机器人操作基准上报告，GAM 相比当前基础模型规模基线更准确、更鲁棒、更快且更轻量。

## 方法

**方法概述：** GAM 将预训练 DA3 几何基础模型在第 12 层切分：浅层独立编码最近多时刻的多视角 RGB，12 层因果 Transformer 融合任务语言、本体状态与动作历史并预测下一时刻几何潜 token 和动作 token，随后由剩余 GFM 深层传播这些预测，再分别通过原几何头和轻量动作头解码未来深度与 8 步动作块；训练联合使用动作、未来特征和未来深度损失。

**核心机制：** 核心机制是在 GFM 的浅层表征已经形成但 DPT 几何头所需的深层传播尚未发生的位置插入 block-causal 预测器。每个时刻的机器人状态、上一动作和多视角几何 token 组成一个时间块，语言 token 全局可见，块因果掩码禁止未来泄漏；预测器用几何槽位估计下一时刻潜状态、用动作槽位估计下一动作 token。动作 token 按视角复制后与未来几何 token 一起穿过剩余 GFM 层，使动作决策必须继续与跨视角三维结构交互，而不是由外接头绕过几何骨干。

**方法拆解：** - 观察编码：DA3-Giant/Track4World 骨干在 Ls=12 切分，浅层对上下文窗口内每个时刻的多视角 RGB 独立编码，保留相机 token 与 patch token 的空间结构。
- 因果未来预测：冻结 T5 提供语言 token，轻量投影把 7 维本体状态和上一动作变成 token；12 层 Transformer 用 block-causal attention 联合预测下一时刻几何潜 token 与动作 token。
- 共享深层传播：单个动作 token 为每个视角复制，与预测的未来几何 token 拼接后通过 GFM 剩余深层；全局注意力继续使用因果掩码，避免时序泄漏。
- 双头解码：原 GFM 的 DPT 深度头把多层未来特征解码为动作对齐的未来深度，轻量动作头聚合上下文中的动作 token 并回归 8 步、7 维动作块。
- 联合训练与在线推理：L1 动作损失、未来特征对齐损失和尺度不变/梯度匹配深度损失按 3:1:3 加权；推理使用 KV cache，每步只处理新观察和上一动作。

**关键要点：** - 关键不是在 VLA 旁边外挂 GFM 特征，而是让未来状态与动作都必须通过同一套几何骨干的深层计算。
- 未来预测主要作为训练期几何动力学监督；实际控制仍是单次前向解码动作块，不需要像视频扩散 WAM 那样迭代生成未来像素。
- 切分层是成败关键：过早预测缺少足够视觉语义，过晚预测又没有足够 GFM 深层去把预测 token 重新投影回可解码的三维流形。

## 结果

**核心结果：** - LIBERO 原始任务成功率 97.6%，接近饱和强基线；LIBERO-Plus 为 85.5%，高于 π0.5 的 84.6% 与 Cosmos-Policy 的 82.4%。
- LIBERO-Plus 相机扰动成功率 83.1%，比 Cosmos-Policy 的 73.4% 高 9.7 个百分点；噪声扰动为 95.3%，也是表中最高。
- GAM 只有 1.4B 参数，单次前向 6.9 ms（约 145 Hz）；对照 OpenVLA-OFT 为 7B/77.8 ms，π0.5 为 3.3B/29.2 ms，Cosmos-Policy 为 2B/382.4 ms。
- 真实机器人四任务的主图汇总报告，ID 相机成功率 65%，相机扰动成功率 52.5%；对应 π0.5 为 55%/30%，Spatial Forcing 为 35%/22.5%。
- LIBERO-Object 消融中，完整预训练模型为 99.6%/89.7%（Orig./Plus）；去掉预训练但保留未来特征和深度监督降至 98.4%/73.4%，三者都去掉则降至 93.6%/50.0%。

**结果表：** | 评测/成本 | GAM | 强对照 | 结论 |
| --- | ---: | ---: | --- |
| LIBERO / LIBERO-Plus | 97.6% / 85.5% | π0.5：96.9% / 84.6% | 原任务持平，扰动下小幅领先 |
| LIBERO-Plus 相机扰动 | 83.1% | Cosmos-Policy：73.4% | +9.7 个百分点 |
| 真实机器人 ID / 扰动相机（主图汇总） | 65% / 52.5% | π0.5：55% / 30% | OOD 下降更小 |
| 模型规模 / 延迟 | 1.4B / 6.9 ms | Cosmos-Policy：2B / 382.4 ms | 约 55 倍更快 |
| 无预训练、无未来损失（Object） | 93.6% / 50.0% | 完整模型：99.6% / 89.7% | 几何预训练决定鲁棒性 |

## 洞察

**核心 insight：** - 这项工作把“世界模型”从像素生成重新定义为在预训练几何流形上预测未来。对控制而言，能否保留与动作相关的深度、尺度、遮挡和跨视角一致性，可能比生成逼真的未来 RGB 更重要。
- GAM 的效率优势来自两层节省：预测对象是中间几何 token 而非像素，推理是一次自回归前向而非多步扩散；因此世界建模监督不必等价于昂贵的在线想象。
- 消融表明几何未来损失在没有预训练时很重要，但在预训练骨干上可被移除而性能几乎不变；这说明主要收益可能来自 GFM 已编码的几何先验，而辅助未来损失更像从零建立鲁棒性的替代监督。

**和已有方法的关系：** - 相对 VLA，GAM 用冻结 T5 处理语言，把大部分模型容量放在三维几何和时序动力学上，因此空间鲁棒性更强，但语言推理上限更低。
- 相对视频 WAM，GAM 不预测未来 RGB/视频扩散 latent，而是在 GFM 的几何潜空间预测未来状态，牺牲像素级生成能力以换取更直接的空间约束与实时控制。
- 相对 Spatial Forcing、ROCKET 等 geometry-aware VLA，GAM 不是蒸馏外部几何特征，而是让 GFM 深层直接参与未来状态与动作解码，把几何从辅助约束升级为主计算基底。

**可借鉴点：** - 可把 foundation model 在中间层切开，把任务专用时序模块放在“已有语义已形成、原解码头仍可复用”的缝隙中；切分层需要通过系统消融寻找。
- 评估几何策略时应把相机扰动、机器人初态、背景、光照和布局拆开报告，避免原始 benchmark 饱和掩盖真正的空间泛化差异。
- 辅助未来预测可只在训练期塑造表示，部署时保留单步动作解码；这为低延迟机器人世界模型提供了比显式视频 rollout 更务实的接口。

## 风险与判断

**局限：** - 语言条件只来自冻结 T5 编码器，论文也明确承认语言推理与常识能力受此限制；复杂指令分解、开放世界问答或需要外部知识的任务不是当前 GAM 的强项。
- 主结果集中在 LIBERO/LIBERO-Plus、RoboCasa 与四个固定真实机器人任务，真实场景每任务约 200 条示范、20 次评测；尚未验证跨机器人形态、移动操作或长时程开放环境。
- 真实机器人 Figure 1 报告扰动相机汇总 52.5%，但 Figure 4 可见四个 OOD 柱值按 80/60/20/40 直接平均为 50.0%；论文没有解释这 2.5 个百分点差异，引用该结果时应核对评测口径或作者勘误。
- 未来深度监督在仿真依赖真值、真实世界依赖 GFM 伪标签；当透明、反光、强遮挡或相机标定误差破坏伪深度时，几何世界模型可能继承教师偏差。

**适用场景：** - 多相机固定机位的通用操作策略，尤其是需要适应相机挪动、机器人初态变化、背景和噪声扰动的桌面操作。
- 算力或控制周期受限、无法承受视频扩散多步采样，但仍希望用未来状态预测作为训练监督的实时机器人系统。
- 已有强几何基础模型和机器人轨迹，希望用较少架构改动把静态三维先验升级为语言条件世界—动作策略的研究。

**最终判断：** - GAM 是几何基础模型进入机器人控制的一条关键系统路线：它用共享骨干证明“预测未来几何 + 解码动作”可以兼顾 OOD 相机鲁棒性和高频推理，值得作为 geometry-native WAM 基线长期跟踪；但其语言推理、跨具身泛化和真实世界评测规模仍不足以支持通用机器人策略的更强结论。
