# UNITAS: A 3D-Native World Action Model for Embodied Manipulation

## 太长不看

UNITAS 不是把深度图简单接到 VLA 上，而是把“看见什么、身体怎么动、世界如何响应”都写成同一度量 3D 坐标系里的点轨迹。机器人夹爪和人类手被表示为 action flow，环境点位移被表示为 scene flow；一个物理时间 tokenizer 让不同采样率与轨迹长度的数据共享接口。1.7B 模型在 LIBERO 达 99.8%，LIBERO-Plus 达 89.1%，RoboTwin Clean/Randomized 达 92.94%/93.04%；在动作条件场景预测中，Moving ADE 从 PointWorld 的 0.656 cm 降到 0.427 cm。

## 直观理解

可以把视频 WAM 理解为“先想象未来画面，再决定动作”，但画面像素并不天然等于物理距离：同一个 10 cm 位移在近景和远景中占的像素完全不同，相机一动，同一物理事件的视觉表现也会变。UNITAS 把预测单位从像素换成世界坐标中的点轨迹。夹爪/手是一组跟踪点，物体和场景也是一组跟踪点；动作回答“这些身体点未来怎么走”，scene flow 回答“这些场景点会因此被推到哪里”。因此同一个表示同时服务可执行控制与后果预测。

## 背景与问题

**动机：** 机械交互发生在度量三维空间中，接触、遮挡、物体位移和末端轨迹都需要物理距离与方向约束。视频 WAM 虽然能借用视频生成先验，但未来图像是视角相关投影：同一运动换个相机会得到不同像素变化，等量像素位移也不代表等量物理位移，这会使空间推理、泛化与控制学习继承不必要的视角噪声。

**问题缺口：** 已有 3D 策略常把几何作为输入提示或辅助目标，PointWorld 之类方法则给定机器人运动后预测场景响应，缺少一个同时从指令生成动作、直接执行动作、并预测环境后果的统一模型。跨机器人、人类手、不同采样率与坐标约定的数据也需要一个共享时空接口，而不是为每种本体维护一套动作语义。

## 论文摘要（英文原文）

World action models (WAMs) aim to answer a coupled physical question: given a task instruction, what motion should the robot execute, and how will that motion change the surrounding world? Most existing WAMs build on pretrained video generators and represent world evolution through images or visual latents. Robotic interaction, however, takes place in metric three-dimensional space, while images are view-dependent projections whose pixel distances do not directly encode physical distances. We introduce UNITAS, to our knowledge the first 3D-native world action model that unifies observations, actions, and scene dynamics in a shared metric 3D frame within each interaction, using a common representation across robot embodiments and human hands. Action flow represents human hands and robot grippers as 3D point trajectories, while scene flow describes scene-point displacements conditioned on these trajectories. World-aligned 3D positional embeddings ground visual tokens with or without depth input, and a physical-time trajectory tokenizer encodes each point trajectory as one token anchored at its current 3D position. This interface supports both direct action execution and action-conditioned scene prediction. With 1.7B parameters, UNITAS achieves the best action-conditioned scene prediction on RoboTwin among the compared methods, with up to 49% lower displacement errors than PointWorld, and state-of-the-art manipulation success, including 99.8% on LIBERO and an average of 85% across real-world tasks.

## 论文摘要（中文翻译）

世界动作模型试图回答一个耦合的物理问题：给定任务指令，机器人应执行什么运动，以及该运动会如何改变世界。现有 WAM 多建立在预训练视频生成器上，用图像或视觉潜变量表示世界演化；但机器人交互发生在度量三维空间，图像只是视角相关投影，像素距离并不直接编码物理距离。UNITAS 将观测、动作和场景动态统一到每次交互的共享度量 3D 帧，并跨机器人本体与人类手使用共同表示。action flow 将人类手和机器人夹爪表示为 3D 点轨迹，scene flow 在该轨迹条件下描述场景点位移；世界对齐 3D 位置嵌入可在有无深度输入时为视觉 token 提供空间锚定，物理时间轨迹 tokenizer 将每条点轨迹编码为一个锚定在当前 3D 位置的 token。该接口同时支持直接动作执行和动作条件场景预测。1.7B 参数下，UNITAS 在 RoboTwin 动作条件场景预测中取得对比方法最佳结果，位移误差较 PointWorld 最多降低 49%，并在 LIBERO 达 99.8%、真实任务平均约 85%。

## 方法

**方法概述：** UNITAS 在一个预测窗口内固定共享世界坐标，将 RGB(-D)、相机内外参、末端状态、历史 action flow 和任务指令作为上下文；点动力学专家生成 action flow 与 scene flow，较小的动作专家生成可执行末端动作块。训练先重建轨迹 tokenizer，再用 rectified flow 联合监督 action flow、scene flow 与控制动作；策略推理时可以完全跳过两个未来流分支，仅输出动作。

**核心机制：** 世界对齐位置嵌入把每个视觉 token 锚定到度量坐标；有深度时直接反投影，无深度时沿相机射线采样 64 个候选深度并用视觉特征学习路由。action flow 与 scene flow 都用“当前点 + 未来位移序列”表示，tokenizer 以秒而非帧号为时间轴，把不同频率和长度的轨迹压缩为一个空间锚定 token，因此 15 Hz 机器人数据、6–10 Hz 人类视频和多视角数据能共享同一个物理时间接口。

**方法拆解：**

- **空间接地**：有深度时由相机内参反投影并变换到世界帧；无深度时在 0.1–2.0 m 间采样 64 个候选深度，通过 Q/K 路由生成世界坐标位置特征，并用可靠深度区域的平均 Fourier 特征监督路由。
- **统一身体表示**：机器人每臂从 URDF 夹爪几何采样 20 个保 correspondence 的跟踪点，人类手使用每手 21 个 MANO 关键点；这些点都变成世界帧 action flow。
- **统一场景表示**：剔除机器人像素后反投影 RGB-D，体素化并最多采样 12,000 个场景查询点；scene flow 从当前点预测未来位移，训练时只用有效对应关系。
- **物理时间 tokenizer**：以 `τ/Tmax` 编码物理时间，最大 3 秒；编码器池化整条轨迹为一个 latent，解码器按请求时间输出位移，历史轨迹使用负时间。
- **耦合专家与注意力**：point dynamics expert 和 action expert 共享观测/语言 KV；scene flow 只条件于 clean action flow，不参与 action-flow 去噪；action command 不看未来流，因此 policy-only 推理无需生成未来世界状态。
- **训练与部署模式**：九个数据源混合预训练 200K step、batch 1024，再按 benchmark 微调；部署时可只输出动作，也可在外部给定 action flow 后进入 simulator mode 预测场景演化。

![架构](https://arxiv.org/html/2610.12099v1/architecture.png)

*点动力学专家和动作专家通过层间 KV 共享，但保留不同输出接口。*

**关键要点：**

- UNITAS 的“3D-native”不在输入端，而在接口层：观测 token、身体点、场景点、历史与未来轨迹都被锚定到同一世界坐标。
- 与视频 WAM 的未来像素不同，scene flow 的监督目标是动作条件下的点级物理位移，能同时评价运动误差、背景漂移和动作—场景一致性。
- 无深度路由不是简单用单目深度替代深度传感器；在 LIBERO-Plus 中，无深度 routed PE 达 84.43%，与真深度 PE 的 84.68% 只差 0.25 个百分点。

## 结果

- **操控基准**：LIBERO 平均 99.8%；无混合预训练也有 99.5%。LIBERO-Plus overall 89.1%，比 π0.5 的 85.7% 和 Cosmos Policy 的 82.2% 高。RoboTwin 2.0 Clean/Randomized 为 92.94%/93.04%，高于 LingBot-VA 的 92.93%/91.55% 和 X-WAM 的 89.8%/90.7%。VLABench SR/PS 为 56.2%/67.6%，高于 π0.5 的 48.1%/62.3%。
- **真实机器人**：每任务 20 次，Organize Books 18/20（90%），Pack the Ball 16/20（80%）；π0.5 分别为 75%/55%，Fast-WAM 为 65%/60%。论文宣称真实任务平均 85%。
- **场景预测**：RoboTwin 上 Moving ADE/FDE/Static ADE 为 0.427/0.825/0.043 cm，Moving Acc@1cm 为 92.31%；PointWorld 为 0.656/1.050/0.084 cm 与 88.22%。相对 PointWorld，三项误差分别降 35%/21%/49%。
- **消融**：无混合预训练 LIBERO-Plus 基线 85.74%。去掉 3D PE 降至 81.35%，其中 camera 扰动从 79.11% 降至 66.73%；去掉 action-flow 监督为 78.89%；去掉历史 action-flow token 为 75.92%，robot 初始状态扰动降 19.87 个百分点；再加 scene-flow 监督升至 86.47%。全部去掉后为 67.58%。
- **效率**：RTX 5090 D 上 policy-only 每 action chunk 55.77 ms，比 6B Fast-WAM 的 156.81 ms 快 2.81×；输出 action+action flow 为 122.51 ms，同时输出 1,024/3,000 scene queries 为 305.49/561.60 ms。

## 洞察

- **表示比模态更关键**：深度输入有帮助，但世界对齐位置嵌入和点流监督才是把不同相机、本体和数据源放进同一学习问题的关键。
- **动作与世界演化可并行也可级联**：action flow 与 action chunk 并行采样，scene flow 再以 clean action flow 为条件；这保留了世界模型的后果预测能力，又不强迫策略执行时生成未来。
- **历史是几何记忆**：action-flow history 对 robot 初始状态扰动影响最大，说明最近运动轨迹提供了当前末端状态之外的动态上下文。
- **跨数据混合的价值来自共同语义**：预训练把 robot、simulation 与 VITRA 人类手数据放在同一 action flow 中，LIBERO-Plus robot/language 扰动分别提升到 94.2%/85.0%。
- **评估要区分 policy-only 与 simulator mode**：前者的 55.77 ms 不能外推到完整世界模型预测；后者需要额外 scene query 数与延迟预算。

## 风险与判断

**局限：**

- **真实任务覆盖仍窄**：仅报告两个真实任务、每个 20 次，且来自相关团队平台；平均 85% 不能代表开放场景泛化。
- **scene flow 依赖查询几何**：推理时需要当前 3D query 点；无深度 routed PE 的策略结果尚可，但世界模型评估仍依赖可用几何或校准。
- **窗口有限**：轨迹 tokenizer 面向 3 秒内的位移，论文结论也承认长交互、更广部署和可靠性预测仍是后续方向。
- **数据与基线不完全等价**：Dex-BEV 参数量未报告，Fast-WAM/Motus 的设置与公开可复现程度也需独立检查；论文未提供完整训练成本之外的逐方法算力对齐。

**适用场景：**

- 需要 Explicit 3D 一致性的桌面/双臂操作，尤其相机位姿、机器人初始状态和语言表达会变化的评估。
- 希望把机器人示范、人类手视频和多本体数据统一到可比较 action 语义中的预训练系统。
- 需要同时研究动作生成和动作条件后果预测的 WAM 实验；可通过 scene query 数调节精度与延迟。

**最终判断：**

- **值得作为 3D-native WAM 的核心参考**。它把此前“3D 输入”“点世界模型”“跨本体动作表示”三条线合成一个统一概率分解，并用策略、世界预测和消融三方面验证接口价值。
- **不能把它理解为通用具身世界模型已解决**。其证据集中在 3 秒预测窗口、仿真为主和少量真实任务；长时序接触、可变形物体、相机标定漂移与无监督真实 scene flow 仍是关键风险。
- **最应跟进的后续问题**：scene flow 监督能否迁移到真实深度噪声；action flow 表示在更多本体和任务上的数据效率；policy-only 与完整世界模型模式的在线规划收益；跨实验室复现与失败案例分析。
